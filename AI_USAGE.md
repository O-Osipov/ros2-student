# Использование ИИ

## PR01

- Использован ИИ: да, Codex (GPT-6), интерфейс Codex desktop.
- Затронутые файлы: README, workflow GitVerse, graph.md, environment.json,
  report.json и эта декларация.
- Помощь: подготовка команд, выполнение опыта через терминалы, оформление
  фактических результатов и локальная проверка workflow.
- Проверка: команды выполнены в закреплённом ROS-контейнере; реальные stdout,
  коды завершения и снимки окна сохранены в evidence/pr01. Результаты
  не сгенерированы вместо запуска ROS. Поля отчёта сверены с этими файлами;
  публичный checker и команды CI выполнены отдельно от оформления текста.
- Это демонстрационное выполнение по поручению владельца курса. Отдельная
  контактная пара не проводилась; время в report.json отражает подготовку
  этого примера, а не нормативную трудоёмкость студенческой работы.

Переписка, личные промпты и секреты не включены.

## PR02

- Использован ИИ: да, Codex (GPT-6), интерфейс Codex desktop.
- Помощь: подготовка пакета, launch, README, workflow GitVerse, проведение
  команд через терминал, оформление evidence и независимое ревью реализации.
- Проверка: пустая и итоговая сборки выполнены в закреплённом Lyrical-контейнере;
  проверен установленный launch, выполнены тесты каркаса. Настоящий turtlesim
  запущен offscreen, сырые ответы CLI сохранены; координаты до/после сравнены
  программно. Нет подмены ROS-процессов сгенерированными результатами.
- Проверены отсутствие подписчика неверного имени, сохранение позы при сбое,
  движение после исправления только имени, остановка по таймауту команды
  и завершение ноды вместе с launch.
- Комплект course kit скачан с платформы и сверен по SHA-256. Контракт отчёта
  и локальные команды CI проверяются отдельно. При исходном оформлении
  удалённый CI ещё не выполнялся; последующая ошибка и её исправление
  описаны ниже.
- Демонстрационный пример по поручению преподавателя, без контактной пары.
  Время отчёта — длительность подготовки примера, не норматив студента.

### Исправление CI ПР02 — 2026-09-21

- Codex диагностировал фактическую ошибку GitVerse `exec: node: not found`:
  старый локальный прогон охватывал только `run`, без JavaScript checkout/post.
- Изменены только workflow и README в новом коммите реализации. `report.commit`
  обновлён; эта декларация и новая evidence оформлены следующим коммитом.
- В чистом закреплённом образе воспроизведено отсутствие Node; bootstrap
  установил Node 22.22.1. Настоящий action с GitVerse выполнен через main/post,
  проверены полная история Git и удаление тестового auth header.
  Использованы локальный Git transport и фиктивный токен, не реальные секреты.
- ROS-код и исходные наблюдения сохранены; повторный опыт с turtlesim не нужен
  для изменения только CI/README и не заявляется. Заново проверены сборка,
  установленный launch, тесты пакета и публичный контракт evidence.
- Новый успешный удалённый run не заявлен. Владелец публикует коммиты и проверяет
  завершение всей job, включая post checkout.

## PR03

- Использован ИИ: да, Codex (GPT-6), интерфейс Codex desktop.
- Помощь: реализация ноды и чистой функции, тесты, сценарий повторения опыта,
  workflow и README, оформление трёх файлов evidence/pr03 по реальным выводам.
- Проверка: четыре теста сначала отказали на отсутствии реализации, затем
  прошли в закреплённом Lyrical. Настоящий turtlesim запускался offscreen:
  измерены граф, 10 секунд команд, поза до/после remap и остановка по watchdog.
  Исходные stdout сохранены в tests.txt. Произведено независимое ревью кода.
- При проверке исправлен сам сценарий завершения: ros2 run перенаправляет
  SIGINT дочерней ноде, поэтому сигнал посылается CLI один раз.
- Только обязательная часть ПР03; маршрут мышью не реализован. Пакет запуска
  и старые evidence сохранены. report.commit указывает отдельный коммит
  реализации; текущие evidence и эта запись фиксируются следующим коммитом.
- Локальный прогон не является удалённым GitVerse CI. Публикацию выполняет
  владелец. Время в отчёте относится к подготовке примера, не к норме студента.
- Чистый повтор выявил задержку обнаружения в CLI: диагностические запросы
  переведены на `--no-daemon --spin-time 2`, добавлено ожидание подписчика.
  После исправления полностью повторены тесты и живой опыт. SHA отчёта
  обновлён на этот коммит реализации; код движения остался прежним.
- Финальный локальный прогон исполнил все run-шаги workflow из чистого клона,
  включая Node bootstrap, реальный опыт, SHA-256 комплекта и публичный checker.
  JavaScript checkout/post в этом прогоне не исполнялись; удалённый run не заявлен.

### Исправление CI ПР03 — 2026-09-27

- Codex прочитал полный публичный лог GitVerse run 1648208: запрос типа
  завершился без stdout/stderr. В закреплённом ROS CLI это код 1 при отсутствии
  топика в локальном графе запроса. Сбой воспроизведён при ограничении CPU.
- Регрессионный тест с поздним настоящим ROS-топиком сначала отказал на старом
  скрипте. Исправление ждёт ожидаемые строки графа в пределах общего дедлайна
  20 с, повторяет только discovery miss/неполный граф. Окна discovery: 2, 4, 8 с.
  Синтаксические ошибки и ошибки ROS не скрываются. Нода patrol не менялась.
- Добавлены пять регрессий, включая неверное количество endpoints, явные ошибки
  CLI и отсутствующий топик; выполнено независимое ревью. Сборка, ROS-тесты
  и живой опыт повторены в контейнере. Новые результаты дописаны в прежние
  evidence/pr03; отчёт ссылается на отдельный коммит исправления.
- Успешный удалённый повтор GitVerse не заявляется: push выполняет владелец.
