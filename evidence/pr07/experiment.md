# Проверка живой симуляции

- Среда: Docker Ubuntu 26.04.1, ROS 2 Lyrical, Gazebo Sim 10.5.0 (Jetty).
  Комплект курса `v1-w10`, SHA-256 архива
  `7a91d388d7bd3def7e058c8da48c32ff27ea6f14dc880a2da169c4102d456874`.
  `workstation.txt` сохранён; предупреждение EGL появляется в логе, но
  камера и лидар реально публиковали сообщения без окна.
- `gz sdf -k` признал модель валидной. Он предупредил о `gz_frame_id` из
  выданной модели; фактические ROS `frame_id` всех сенсоров проверены отдельно.
- `simulation.launch.py` создал один сервер Gazebo, `robot_state_publisher`,
  один `parameter_bridge` и два адаптера. Процессы оставались активны во
  время независимых проверок.
- `sensors.json` содержит измеренные frames, частоты по stamp симуляции и
  частоты по настенным часам. На первом интервале real-time factor был
  около 0,466. Лидар, IMU и одометрия по симуляционным меткам выдержали
  10/100/50 Гц; камера дала около 9,86 Гц вместо заданных 15 Гц.
  Отдельный `ros2 topic hz` позднее показал около 6,9 Гц для лидара и
  3,2–4,4 Гц для камеры по настенным часам. Замедление объясняется
  программным рендерингом и нагрузкой; равенства с SDF `update_rate`
  по настенным часам не ожидалось.
- `bridge-info.txt`: сенсоры опубликованы с `BEST_EFFORT`, одометрия и
  команда — с `RELIABLE`, `/tf_static` — `TRANSIENT_LOCAL`.
- `safe-command.txt` содержит свежий stamp, скорость 0,4 м/с и угол 0,2 рад.
  `ros-command.txt` и `gz-command.txt` показывают одинаковые
  `linear.x=0,4` и `angular.z≈0,101355` рад/с.
- `odom-before.txt` → `odom-after.txt`: x от почти 0 до ≈2,584 м.
  `physical-motion.json` подтверждает по Gazebo `dynamic_pose` движение
  корпуса x≈0→2,507 м и изменение ориентаций всех четырёх колёс.
  Значения позы Gazebo и одометрии здесь сравниваются по факту движения,
  а не объявляются тождественными координатами. `tf-fixed.txt` подтверждает
  доступность `odom→base_link` через tf2.
- `record.log` и `bag-info.txt`: MCAP с `--use-sim-time` записан в
  `fixtures/pr07-sensors` (каталог игнорируется Git). `ros2 bag info`
  показал 33,366 с по симуляционному времени и ненулевой счётчик всех семи
  обязательных топиков, в том числе `/tf_static`.
- `colcon test --packages-select course_simulation`:
  36 тестов, 0 ошибок, 0 провалов, 1 пропуск (общая среда colcon).
