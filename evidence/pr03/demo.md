## Работа ноды

`rclpy.init()` инициализирует ROS-контекст, `Patrol` создаёт подписку
`/turtle1/pose`, издателя относительного `cmd_vel` и таймер 0,1 с.
Обработчик подписки сохраняет последнюю `Pose`; обработчик таймера берёт её
и публикует `Twist`. Чистая функция `choose_command(None)` возвращает
`(0, 0)`, после получения позы — `(0.5, 0.3)`. `rclpy.spin()` обслуживает
обработчики; SIGINT, эквивалентный Ctrl+C, завершает ноду и освобождает
ресурсы. Завершение процесса само по себе не отправляет команду остановки:
после исчезновения команд turtlesim останавливается по своему watchdog.

## Опыт с turtlesim

До запуска симулятора `ros2 run patrol patrol --ros-args -r
cmd_vel:=/turtle1/cmd_vel` передал наблюдателю пять нулевых `Twist`.
После запуска turtlesim тип `/turtle1/pose` определён как
`turtlesim_msgs/msg/Pose`.

Без remap команда `ros2 run patrol patrol` создала издателя `/cmd_vel`.
`ros2 node info /patrol` подтвердил подписку на позу и издателя команды.
`ros2 topic info /cmd_vel --verbose` показала одного издателя и ноль
подписчиков. На `/turtle1/cmd_vel` тогда был один подписчик turtlesim и
ноль издателей. После двух секунд поза осталась
`(5.54444456, 5.54444456, 0.0)`. Дефект вызван несовпадением **полного
имени** топика: относительное `cmd_vel` разрешилось в `/cmd_vel`.

Затем изменён только аргумент запуска:

```bash
ros2 run patrol patrol --ros-args -r cmd_vel:=/turtle1/cmd_vel
```

Теперь у `/turtle1/cmd_vel` один издатель и один подписчик. За **10,014 с**
наблюдатель получил **100 сообщений**; измеренная частота **10,001 Гц**.
В каждом сообщении `linear.x=0.5`, `angular.z=0.3`.
Поза изменилась с `(5.54444456, 5.54444456, 0.0)` до
`(3.97573185, 7.78509188, -1.92478526)`. После SIGINT издатель исчез;
через ожидание watchdog обе скорости позы стали нулевыми и координаты
перестали меняться. Симулятор завершён после опыта.

Временные подписчики и CLI-команды добавляют конечные точки в граф на время
измерения. Для доказательства разрыва использованы снимки графа до запуска
измерителя, а для доказательства исправления — полный вывод в tests.txt.
